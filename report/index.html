Methodology & data quality notes
  • ETL in Python/pandas: two day-first date formats normalised (D/M/YYYY and DD-MM-YYYY); durations recomputed from timestamps (the raw Handle_Time_hrs column is unreliable).
  • ITIL measures: MTTR = mean hours Open→Resolved; MTBF = mean days between consecutive incidents on the same CI (biased by the volume ramp in this extract); First Contact Resolution = % of resolved tickets never reassigned (proxy); Escalation rate = % reassigned 2+ times; SLA compliance uses the targets below; Major incidents = P1+P2.
  • SLA targets are a documented assumption: P1 ≤ 1d, P2 ≤ 3d, P3 ≤ 7d, P4/P5 ≤ 14d.
  • Resolution timestamps only exist from Oct 2013 onward, so earlier months show zero resolutions — an artifact of the source extract, not of the pipeline.
  • Pipeline & CI/CD: etl/ → GitHub Actions → this report (D3.js) on GitHub Pages.
